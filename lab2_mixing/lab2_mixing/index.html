Лабораторная работа №2. Моделирование и оптимизация процесса смешивания лакокрасочных материалов

Главная страница

Проект: «Моделирование и оптимизация технологического процесса смешивания».

Цель: разработать интерактивное веб-приложение для математического моделирования, визуализации и оптимизации процесса смешивания компонентов ЛКМ.

Задачи:

  1. Рассчитывать однородность смеси H(t, n) по модели.
  2. Построить графики H(t) и H(n), сравнить режимы.
  3. Рассчитать условные энергозатраты E(n, t).
  4. Найти режим с минимальными энергозатратами при H ≥ требуемой.
  5. Провести не менее 5 экспериментов и сделать выводы.

Технологический процесс: смола G₁ (содержит растворитель C₁%) и растворитель G₂ (C₂ = 100%) подаются в смесительный узел объёмом V. Мешалка вращается со скоростью n об/мин. На выходе — готовый ЛКМ расходом G = G₁ + G₂ и концентрацией растворителя C.

Теоретическая часть

Смесительные устройства применяют в производстве мебели, фанеры, ДСП для смешивания жидкостей, порошков, древесной пудры со связующим, для поддержания клеев и лаков в нужной вязкости; также — при приготовлении напитков, очистке воды и т. д.

Модель строится на законе сохранения материи в динамике: приход = убыль + приращение.

  • приход: (G₁C₁ + G₂C₂)·dt
  • убыль: G·C·dt, G = G₁ + G₂
  • приращение (накопление в смесителе): V·dC
(G₁C₁ + G₂C₂)·dt = G·C·dt + V·dC

Деля на G·dt, получаем дифференциальную модель (1.16):

T·dC/dt + C = Pᵢ, Pᵢ = (G₁C₁ + G₂C₂)/(G₁ + G₂), T = V/G

Решение (1.17):

C(t) = C₀·e−t/T + P·(1 − e−t/T)

Параметры процесса. Входные: G₁, G₂, C₁, C₂, V. Управляемые: скорость мешалки n, время смешивания t. Выходные: концентрация C, однородность H, энергозатраты E.

Идентификация постоянной времени

Производная находится численно: dC/dt ≈ (Cⁿ⁺¹ − Cⁿ⁻¹)/(2Δt). Для обобщённой модели A₁·dC/dt + A₂·C = Pᵢ коэффициенты определяют методом наименьших квадратов (нормальная система 1.23–1.24):

Σx₁²·A₁ + Σx₁x₂·A₂ = ΣPx₁; Σx₁x₂·A₁ + Σx₂²·A₂ = ΣPx₂

Результат из методички: A₁ = 1,029; A₂ = 0,759, откуда T ≈ 1,029; модель адекватна при отклонении ΔT ≤ 2 %.

Математическая модель

Для оценки качества смешивания в лабораторной работе используется модель однородности:

H(t, n) = 100·(1 − e−k·n·t)

H — однородность, %; t — время, мин; n — скорость мешалки, об/мин; k — коэффициент интенсивности смешивания (по умолчанию 0,001).

E(n, t) = a·n²·t, a = 0,0001

E — условные энергозатраты (усл. ед.). Время достижения требуемой однородности H*: t* = −ln(1 − H*/100)/(k·n).

Задача оптимизации: E(n, t) → min при H(t, n) ≥ H*, 100 ≤ n ≤ 500, 1 ≤ t ≤ 20.

Анализ: при минимальном допустимом t* энергозатраты E = a·n·(−ln(1 − H*/100))/k растут с n линейно, поэтому оптимум — наименьшая скорость, при которой H* достигается за ≤ 20 мин: n_min = −ln(1 − H*/100)/(k·20). Алгоритм ниже находит это перебором по сетке и сверяется с аналитикой.
